## 🧭 本节定位

皮克斯有条信条——**"把角色涂成全黑，它应该依然能被认出来。"**这就是剪影的力量。本节讲怎么从一个黑影子开始，一步步设计出有辨识度、有性格、让玩家记住的像素角色。

## 👤 为什么米老鼠、马力欧、索尼克的剪影都是独一无二的？

试一个思维实验：把你最熟悉的三个游戏角色的细节全部抹掉——涂成全黑——变成三个纯黑色的影子。你还能认出谁是谁吗？

能。马力欧的剪影——帽子+大鼻子+短粗身体。索尼克——尖刺头+细长腿。米老鼠——两个巨大的圆耳朵。这就是**剪影辨识度**——角色设计最底层的竞争力。

很多新手画像素角色的第一反应是：打开 Aseprite，直接开始抠眼睛、嘴巴、衣服褶皱。这是错的。你花 20 分钟做的"精致的眼睛"，在游戏画面缩小到 32×32 的时候——只剩 2 个像素，什么都分辨不出。但如果角色的**外轮廓**够独特——玩家隔着屏幕 3 米远也能认出"那是我的飞机"。

这个道理和前端开发中的"移动优先"设计（Mobile First）一模一样——你先确保在最苛刻的条件下（小屏幕 / 小尺寸像素角色），核心信息（布局 / 剪影）是成立的，然后再往上加细节。如果你在 32×32 的剪影都分不清两个角色，加再多 1px 细节也没用。

## 🎨 四层设计流程：从黑影子到活角色

这不是什么高深理论——这是实操流程。每次画新角色，按这个顺序来，你不会在"画到一半发现比例错了"的坑里反复跳。

### 第一层：剪影（纯黑）

用纯黑色画出角色的外轮廓。不需要任何内部细节。这一刻你只关注三件事：

- **辨识度：** 只看轮廓能不能认出这是什么——飞机、人形、怪物？
- **姿态动感：** 即使是 static 站立，也要有微妙的不对称——一侧机翼微翘、身体略向前倾。完全对称的剪影看着像标志牌，不像活物。
- **比例：** 像素角色的经典比例是 2-3 头身（身体高度 = 2-3 个头的高度）——这是 Q 版的甜点区。1:1 太萌（适合图标），4:1 太写实（像素量不够表现）。

### 第二层：主色块

在剪影上用主色填充每个区域——机翼是一种颜色、机身是另一种——但还不做明暗。这一层你确定**颜色分区**：哪些部位是一个颜色、哪些是另一个。好的分区本身就是信息——马里奥的背带裤把身体"切"成红色上衣区和蓝色裤子区，你不需要画腰带也能感知到结构。

### 第三层：明暗

在色块上加上亮面和暗面。用 Phase 5 的技巧——球体部位渐变、平面部位硬切。光源方向必须一致——建议左上 45°。

### 第四层：细节

最后——也是最少的时间——画眼睛、标志、纹理、武器的微调。这些细节是"锦上添花"，不是"雪中送炭"。如果你的角色在前三层都立不住，加再多细节也救不回来。这就像你在 Vue 组件的模板结构（前三层）都没定好的时候，不应该去调 CSS 动画（第四层）。

### 阵营配色：蓝白 = 友方，红黑 = 敌方

这是一个被无数游戏验证过的色彩心理规律：蓝/白/灰组合传递"科技感、安全、可信任"——玩家飞机、护卫角色、友好 NPC。红/黑/橙组合传递"威胁、侵略性、危险"——敌方单位、Boss、陷阱。这不是游戏界的"发明"——这是人类从远古时代继承的色彩直觉（红色=血/火/危险）。利用这个直觉，让玩家在 0.1 秒内判断"这个该打还是该保护"，不需要任何文字说明。

## 🔧 动手：三架敌机剪影设计挑战

打开 Aseprite，做下面这个设计练习。这是你为飞机大战设计敌机的第一步。

1. **小型侦察机（16×16，纯黑色）：** 新建 16×16 画布。用纯黑色画一架小型敌机的剪影。目标：做出"快速、轻盈、数量多"的感觉。策略——细长三角翼造型，翼展宽、机身窄。对称设计（Aseprite 里可以用 Edit → Flip Horizontal 检查对称性）。
2. **中型战斗机（24×24，纯黑色）：** 新建 24×24 画布。用纯黑色画一架中型敌机的剪影。目标：做出"有威胁但不致命"的感觉。策略——多边形主体，可能有两个引擎喷口，翅膀后掠。
3. **大型 Boss（48×48，纯黑色）：** 新建 48×48 画布。用纯黑色画一架大型 Boss 的剪影。目标：做出"压迫感、不对称的恐怖"的感觉。策略——不规则的大型轮廓，可能像螃蟹、蜘蛛、或重型战舰。不对称设计——让玩家感觉"这不像正常飞机，很危险"。
4. **测试：** 把三张剪影导出 PNG，给一个不玩游戏的朋友看，问：哪个最危险？哪个最快？哪个是 Boss？——如果朋友三秒内能答出来而且答对，你的剪影设计就成功了。

做完剪影后，挑一架你最满意的，完成完整的四层流程——主色块 → 明暗 → 细节。然后和初始的纯黑剪影对比——你会惊讶：一个好的剪影，即使没有内部细节，已经"像"一个完整的角色了。

## 🔗 课外延伸

- **皮克斯的角色设计 22 条规则：** 皮克斯故事艺术家 Emma Coats 在 Twitter 上发布过 22 条角色设计规则，其中和剪影直接相关的有："你 admire 一个角色更多是因为他努力尝试而不是成功"（给角色设计"脆弱点"，而不是完美的英雄剪影）；"把角色放到一个他完全不适合的处境里"（设计的剪影要能表达"不适感"）。这对游戏角色设计有深远的启发——不是所有角色都要帅，很多令人难忘的角色是因为"有特点"。
- **《空洞骑士》的剪影哲学：** Team Cherry 的三个澳大利亚人花了 3 年做出了《空洞骑士》。游戏里所有角色都是黑白灰+少量单色，但辨识度惊人——因为设计师把几乎所有精力都放在了剪影和姿态上。主角的"圆头+小角+披风"三个元素构成的剪影，在任何一个场景里都是即刻可辨的。去搜几张《空洞骑士》的角色设计稿（Team Cherry 有公开发布过），看他们怎么从剪影开始迭代——这是一个活生生的教材。
- **Vue 组件设计和角色设计的共通之处：** 好的 Vue 组件——你一眼就能通过 props 名称和 slot 结构看出它是干嘛的，不需要读实现代码。好的像素角色——你一眼就能通过剪影和配色看出它的阵营和角色，不需要看属性面板。两者的核心原则一致：**接口（剪影/props）是最重要的设计决策**，实现细节（内部明暗/组件逻辑）是第二位的。

## ✅ 自测清单

1. 为什么"从剪影开始"比"从细节开始"更高效？如果在画完细节后发现剪影不好看，你要改多少东西？反过来，先确定剪影再填细节——为什么修改成本更低？
2. "蓝白 = 友方 / 红黑 = 敌方"这个色彩规律是有心理学依据的——试着从人类进化的角度解释它的根源。
3. 给你 250 毫秒看一个像素角色的剪影，你能判断它的阵营、类型和大概的性格吗？如果不能——设计师在哪个环节出了问题？
