## 🧭 本节定位

像素画的画笔就是你的手。就像你用 VS Code 写 Vue 而不是用记事本——选对工具，工作流快三倍。这一节不讲理论，**就讲 Aseprite 怎么用**。学完后你打开 Aseprite 不会觉得"这是啥"，而是知道每个按钮在干什么。

## 🖱️ 为什么不能用 Photoshop？

你可能在想——我不是有 Photoshop 吗？Sketch 不行吗？Figma 呢？

行，但不行。这就像你用 `textarea` 写 TypeScript——语法上没问题，实操上你会疯掉。

原因只有一个：**抗锯齿**。PS、Sketch、Figma 的画笔默认都是抗锯齿的——你画一个黑点，它的边缘会被自动"柔化"成深灰、中灰、浅灰的过渡。这叫"好看"。但在像素画里，这叫"灾难"。像素画要的是**像素完美（Pixel Perfect）**——一个像素就是一块纯色，没有半透明过渡，没有模糊边缘。因为你的作品会被放大 2 倍、4 倍、8 倍展示，任何 0.5 像素的模糊在放大后都变成了一个尴尬的污块。

而 Aseprite 的铅笔工具——它的核心不是"画"，而是"放"像素。你点一下，就放一个颜色块。没有模糊，没有过渡，100% 精确。这和你在 CSS 里写 `box-shadow: 0 0 0 2px black` 而不是 `blur` 是同一个道理——你要的是清晰，不是柔和。

Aseprite 由阿根廷程序员 David Capello 从 2001 年开始一个人开发，到今天已经超过 20 年。代码在 GitHub 上完全开源（`aseprite/aseprite`），但编译后的二进制文件需要付费购买（约 20 美元）——这是一种"开源但付费"的有趣商业模式。一个人，20 年，做出的工具被全球像素画师当作标准——这件事本身就值得你尊敬。

## ⌨️ Aseprite 的"五件套"：你应该刻进肌肉记忆的操作

打开 Aseprite 后你看到的界面大致分成四个区域：中央是画布，左侧是工具条，右侧是调色板面板，底部是时间轴（没错，它自带帧动画系统）。现在跟着我过一遍五个最核心的操作——你可以边看边在 Aseprite 里试。

### 1. 铅笔（B）—— 你的主力武器

按下 B 键激活铅笔。现在在画布上点一下——你放了一个像素。按住鼠标左键拖动——你画了一条线。这就是像素画的基本动作。铅笔是**像素完美**的：你放的就是一个纯色方块，没有被柔化，没有被抗锯齿。

按住 Shift 再点击另一个位置——Aseprite 会自动在两个点之间画一条**直线**。像素画的直线不是几何学里的"无限细直线"——它是一串像素构成的近似直线。Aseprite 会用最优的像素排列让它看起来尽可能直。

### 2. 油漆桶（G）—— 一键填色

按下 G 键激活油漆桶。点击一个封闭区域，整个区域会被填充为你当前的颜色。这和 Photoshop 的油漆桶一样——但有一个关键区别：Aseprite 的油漆桶也有"抗锯齿"选项，默认是关闭的。保持关闭——像素画世界里一切都要锐利。

### 3. 图层（Shift+N）—— 分离关注点

图层面板在右侧。新建图层：Shift+N。这个和 Photoshop 的图层逻辑一模一样，和 Figma 的图层也一模一样。像素画的图层不是用来"做特效"的——是用来**分离不同的视觉元素**的。比如角色图层和背景图层分开，方便你单独导出或修改。后面做动画的时候，你还会在同一个图层上画不同帧——那是时间轴的事。

### 4. 洋葱皮（F3）—— 动画师的透视眼

"洋葱皮"是动画师的行话，意思是在画当前帧的同时能看到**前后帧的半透明叠影**。这就像你在 Vue DevTools 里同时看到前后状态——它帮你判断"这一帧和上一帧的位移够不够"。按下 F3 切换洋葱皮开关。刚开始你可能觉得画面变乱了——坚持用，习惯后你会离不开它。

### 5. 调色板管理—— 锁定你的色彩决策

右侧的调色板面板不是"给你参考"的——是**你创建并锁定颜色方案**的地方。你可以在面板里创建、命名、保存调色板。比如创建一个叫"player-blue"的调色板，里面只有 4 种蓝色。之后画所有玩家相关内容时只从这个调色板取色——这保证了整个游戏的色彩一致性。这就像你在 Vue 项目里定义了 CSS 变量 `--color-primary`，然后在所有组件里引用它，而不是到处写 `#3a7bd5`。

## 🔧 动手：10 分钟 Aseprite 初体验

现在就打开 Aseprite（如果还没装：去 `aseprite.org` 下载试用版或购买正式版），跟着做这个快速练习。每一步做完后停下来看一眼效果——边做边看比死记硬背快得多。

1. **新建画布：** File → New，设置 Width=32, Height=32。Color Mode 选 RGBA（支持透明通道，像素画经常需要透明背景）。点击 OK。
2. **铅笔轮廓：** 按 B 激活铅笔，在画布中央画一个简单的外轮廓——比如一棵树的轮廓：底部宽一点，顶部收窄。不用画满，就画外圈一圈。
3. **油漆桶填充：** 按 G 激活油漆桶，在轮廓内部点击填充。你的树现在有了颜色。
4. **Shift 直线：** 按 B 回到铅笔，按住 Shift，在树的底部点击——画一条水平的地面线。像素画的地面不需要复杂。
5. **图层 2 高光：** 按 Shift+N 新建一个图层。在图层 2 上，选一个比树颜色亮一点的颜色（在调色板里调整亮度滑块），在树的左上方点 3-4 个像素做"高光"。现在你的树有了立体感——虽然还很粗糙，但方向是对的。
6. **撤销与重做：** 按 Ctrl+Z 撤销，Ctrl+Y 重做——和所有软件一样。像素画犯错很正常，别怕撤销。
7. **保存：** File → Save As → 保存为 `my_first_tree.aseprite`。**.aseprite 格式保留了图层、调色板、动画帧——是你将来可以随时回来修改的"源文件"**。这就像你保存了 `.vue` 文件而不是只导出编译后的 HTML。

完成后你就有了一棵像素树和一个可编辑的源文件。记住这个流程——之后每一节你都会用到它。

## 🔗 课外延伸

- **David Capello 和 Aseprite 的传奇：** 2001 年，阿根廷布宜诺斯艾利斯的一个程序员开始写一个像素画编辑器——最初是一个 Windows 上的小工具，用来画 RPG Maker 的素材。后来他把它移植到了 Allegro 图形库，再后来完全重写了架构。20 年间，Aseprite 从一个人自用的工具变成了全球像素画师的标准工作台。这大概是独立开发者最浪漫的故事之一：**做自己需要的东西，然后发现全世界都需要它**。
- **为什么"像素完美"的铅笔和 PS 的抗锯齿画笔不兼容：** Photoshop 的画笔在底层用的是双线性采样（Bilinear Sampling）——它在你要画的像素和相邻像素之间计算过渡色。这在照片处理中是好事（边缘看着自然），但在像素画中是坏事（一个"黑色线条"变成了黑-深灰-中灰-浅灰四条线）。Aseprite 的铅笔用的是最近邻采样（Nearest Neighbor）——没有任何计算，你要什么色就放什么色。这和 CSS 里 `image-rendering: pixelated` 和 `image-rendering: auto` 的区别一模一样。
- **快捷键肌肉记忆策略：** 今天你不需要记住所有快捷键。先记住 5 个：B（铅笔）、E（橡皮）、G（油漆桶）、Ctrl+Z（撤销）、Shift（锁定直线）。这 5 个够你完成 80% 的像素画工作。其他的等你需要的时候再学——就像你不需要记住 Vue 的所有 API，但 `ref`、`computed`、`watch` 是每次都要用的。
